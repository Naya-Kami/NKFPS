# 女性7人のキャラクターデザイン再レビュー

現代衣装版のレビューで、戦場での使いやすさ、可愛さと色気、顔と体型の整合性に課題が出た。現代衣装版は比較用の試作とし、以下を戦闘向けデザインの見直しに使う。

| 指摘 | 次の制作で見直す点 |
| --- | --- |
| 服装と戦場での動きが噛み合っていない | 走る、しゃがむ、スライド、壁走り、照準、リロードを想定して、裾・袖・靴・装備の位置を決める。布が巻き込まれず、武器や手足と干渉しにくい構造を優先する。 |
| 衣装に可愛さや色気が足りない | 人物ごとに襟、ウエスト、丈、配色、素材を組み合わせる。例えばラップ服の斜めのラインを短丈の戦闘ジャケットへ取り入れ、動きやすいボトムとブーツを合わせる。装備を付けた状態でも、服のシルエットに個性と魅力が出るようにする。 |
| 顎が尖って三角形に見える | 頬から顎角、顎先までの幅と丸みを一緒に見直す。正面・斜め・横で確かめ、輪郭、目鼻の位置、口元を必要に応じて大きく作り直す。 |
| 体型に色気が足りず、顔との組み合わせにも違和感がある | 頭身、首と肩、胸から脇、腰からヒップと脚へのつながりを全身で見る。体の厚み、曲線、姿勢を人物ごとに調整し、顔の印象と合う体型を選ぶ。衣装を着た状態で、横と斜め後ろからも輪郭を確かめる。 |

次の試作では、各キャラクターの役割と性格を出発点に、顔・体型・衣装・装備をひとつの組み合わせとして評価する。まず同じカメラと照明で全身・顔の候補を並べ、表情と戦闘姿勢での見え方を確認する。ゲーム内の戦闘動作が実装された段階で、衣服と装備の干渉を動作中にも確認する。
