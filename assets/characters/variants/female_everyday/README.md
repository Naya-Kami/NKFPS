# PROJECT VELOCITY 現代衣装版の3Dモデル

成人キャラクター7人のGLBです。骨格、ウェイト、待機アニメーション、テクスチャを各ファイルに収録しています。Blenderなど、glTF 2.0対応のツールで読み込めます。

現代衣装版は外観を比較するための試作です。戦闘用としての改修方針は[キャラクターデザイン再レビュー](../../../../docs/character-art-review.md)にまとめています。
